## How to explore

Start with each project README for the question, methods, findings and limitations. PDF reports provide a readable overview. Excel, Power BI and Tableau files need suitable software for their native features. Download Power BI files to explore them in Power BI Desktop; they do not become interactive on GitHub.

## About the evidence

Campaign proposals and simulations are labelled throughout. Predicted outcomes are not causal findings or achieved commercial results. The two GA4 analyses use separate periods and definitions. Source material remains attributed to its original provider. No blanket open-source license has been applied to third-party datasets or materials.
